A **hap** (short for *happening*) is an event that will happen at a particular moment, such as `note("c3 -")`. They have a start point and an end point.

## name
According to [Strudel's FAQ](https://strudel.cc/learn/faq#what-is-a-hap), the name hap was chosen for this reason:

> We would have called it ‘event’ if this particular name wasn’t used by JavaScript to describe things that happen on html pages, like clicking on a button or hovering over a line of text.

> Since strudel is written in JavaScript, this confusion of having the same name for different things is avoided by calling events ‘haps’.
