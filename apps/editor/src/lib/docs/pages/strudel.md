**Strudel** is a live-coding platform that Lovechild is built on top of. Strudel is very cool.

There are parts of the Strudel API that I dislike, such as the inconsistency between [[sound()]] and [[s()]] being different names for the same function, but [[note()]] and [[n()]] being different functions. Or, the inconsistency with camel case, like [[slowcat()]] and [[degradeBy()]].

Despite that, I don't plan on forking the Strudel repo, or adding more functions. What works with Lovechild will work in Strudel.
